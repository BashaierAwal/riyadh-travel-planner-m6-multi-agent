## Reproduction and remaining clarification

The original M4 processing assigned project place IDs, mapped interests and assigned budget categories. A current upstream download is not automatically identical to these frozen processed files. Replacing them with a newer source release would invalidate the original fingerprints and is outside this revision.

The source references and displayed licences have now been checked. Redistribution clearance is still unresolved for the restaurant source and the conflicting shopping-source description. The approved local files and published historical evidence have been preserved. No claim of complete licence clearance is made. If a source owner does not permit redistribution, the release must use an authorised download and documented processing step instead of publishing that CSV; it must still verify the expected processed-file hashes. A link to another public copy is not a substitute for permission.
